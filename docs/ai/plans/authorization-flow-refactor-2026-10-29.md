# 授权与广告账户获取流程重构

> 文档属性：AI 辅助实施计划。适用范围：本地 Go 授权应用层、CLI/MCP 入口和账户发现适配器。权威边界：计划不代表实现、真实 OAuth 或已安装桌面插件已验收；当前行为以源码、测试和正式授权合同为准。

> 状态：2026-10-29 本地实施与隔离验证完成；2026-10-30 使用仓库最新构建补充完成真实千川授权的账户同步及显式改绑验收。以下原实施范围和隔离验证记录保留当时边界；真实验收范围见文末，不代表其他渠道、实际桌面插件升级或跨平台运行已验收。

## 已核对的依据与范围

参考 StudioX 的 `OceanEngineCallbackExecutionService` 与 `OceanEngineCallbackAdvertiserMethods`：换取 Token，获取官方登录用户 UID，保存授权，然后按账户角色获取广告主、完成分页、去重、批量获取详情。StudioX 回调只报告账户同步任务已投递；本地 Runtime 继续通过既有会话合同报告账户同步完成后才能恢复业务。

2026-10-29 的实施只修改仓库代码与文档并执行隔离验证。保留已有工作树改动、已有授权 ID 和凭据引用格式；不读取真实凭据，不运行真实 OAuth，不安装插件，不提交、推送或发布。SQLite 授权状态整体迁移属于独立范围，本次复用现有安全凭据库、账户快照事务和刷新锁。

## 实施清单

- [x] **统一授权业务编排**。开发内容：CLI/MCP 共用授权 Service，按换码、用户身份核验、凭据及授权保存、账户同步分阶段执行；会话协调器只处理生命周期。验收内容：两个入口均完成相同阶段，重复回调只兑换一次，取消/过期等待 worker 收尾。
- [x] **绑定官方授权身份**。开发内容：调用 `/2/user/info/`，记录渠道、App ID 和官方 UID；明确既有授权重新登录的身份边界，同一已验证用户与 App 再次登录复用唯一既有 grant，无法确定身份的旧记录不自动合并。验收内容：缺 UID、App/用户不匹配、重复身份及跨渠道测试通过，身份核验失败不激活凭据。
- [x] **独立保存授权与恢复账户同步**。开发内容：保存新凭据后将 grant 标为待同步，账户发现失败保留该凭据及旧快照，禁止业务使用待同步范围；重新授权也能使用同一 grant 补同步。验收内容：失败后不重复 OAuth，凭据保存失败保留原 revision，旧分页结果不能覆盖新 revision。
- [x] **明确角色获取接口**。开发内容：授权账户列表与账户展开使用参考项目的账户发现域名，广告主、千川店铺、客户中心、EBP 分别调用对应服务，保留已有代理商/星图边界；分离角色展开实现与账户发现总流程。验收内容：隔离 HTTP/SDK 夹具覆盖各角色、渠道参数、分页、共享广告主、失效账户、批量详情校验和失败不覆盖快照。
- [x] **同步合同与分发验证**。开发内容：更新授权恢复合同、配置/快速开始和未发布更新日志，重建本次源码对应的 Plugin Runtime。验收内容：相关 Go 测试及 race 检查、构建/分发校验通过；如实记录未执行真实 OAuth 和桌面 Host 验收。

## 2026-10-30 千川真实账户验收

- 用户另行要求发起千川授权并重新获取广告账户，随后明确确认将重叠根账户改绑到本次新授权。本轮使用先前 OAuth 已保存的授权补同步，没有再次发起 OAuth，也没有创建或修改投放计划。
- 真实返回暴露的两处阻断已修复并纳入回归：`PLATFORM_ROLE_AWEME` 保留非广告主角色提示后继续展开其他账户；店铺同时返回 `list` 和 `adv_id_list` 时优先使用 `list`，仅在 `list` 为空时兼容 `adv_id_list`，避免将同一批 ID 合并两次。
- 验收前确认已安装插件连接仍运行旧二进制，缺少上述抖音号处理。取消尚未确认的旧实例同步会话后，直接通过仓库最新构建的 macOS arm64 二进制建立独立 MCP stdio 实例，调用相同的 `start_account_sync`、`get_authorization_session` 和本地授权查询工具；未安装或替换真实插件，未通过 CLI 业务路由绕过 MCP。
- 用户确认改绑后，真实会话返回 `completed`、`can_resume=true`、`sync_required=false`。保存了 23 个根账户和 150 个广告主，目标授权的 `pending_account_sync=false`；150 条广告主映射均唯一指向该授权，无歧义。与旧快照相比新增 2 个广告主、移除 17 个，总数由 165 变为 150；这里仅记录快照差异，不据此推断权限变化原因。
- 通过已安装插件的本地授权查询再次核对同一共享状态，确认上述快照已保存、generation 从 23 增至 24；成功页面也显示授权及账户同步完成。验收结束后独立 MCP 实例正常退出，退出码为 0。
