## 已交付实现

- 公开 156 项目录保持不可执行的原始快照；正式执行合同另行编译，156 项均有固定 GET 映射，153 项 `contract_verified`、3 项 `contract_limited`，分为 11 组。155 个真实输入 Schema 与公开 GET/响应字段是输入依据；远端未提供输出 Schema，本地不冒称其已验证输出。
- 正式业务 MCP Adapter 使用固定端点、按授权修订/发现配置隔离的会话池、兼容 Schema 检查、Token 修订回收、有界预算、取消/超时和 SDK/MCP 共享读取冷却。原始数字先按 `json.Number` 解码，再投影安全字段。
- `business_policy` 在启动时固定模式、工具集、主体与授权白名单；MCP/CLI/Token 准备共用 Core 检查。默认 `plan` 与四个业务工具集，资料默认关闭。工具可见不代替授权；父子关系需要当前授权记录及更窄子账户限制。
- 九个正式入口覆盖目录、精确查询、账户健康、计划诊断、素材标签、投放建议和三个 SDK 报表任务。默认 MCP 35 项，启用资料后 38 项；CLI 能力 81 条。Skill 高频直接调用、长尾检索窄目录，不因缺工具改走等价 CLI。
- 素材作品定位保留本批 F2、官方达人、归属、商品和素材身份核验；支持准确可见抖音号补充缺失身份，昵称只命名。请求最多 100 作品、30 个不同目标商品，不生成计划预检或写入。
- D1 三项查询固定为文档搜索、精确 Schema、Go/Java 示例；独立系统保护元数据及既有授权 App 引用已实现，App 变化使绑定失效。配置先验证三项 Schema 再保存并回读，无业务 Secret/Token，资料失败不影响业务路由。

## 有限真实只读证据

沿用用户授权的上次预检账户，仅进行少量真实只读联调。余额、配额通过；商品全域控成本计划在同一日期/过滤/字段/排序下读取两页，每页 10 项，各页身份与 SDK 相同，分页仍有更多数据，因此保持不完整。长 ID、原始数字、金额单位与未请求字段 null/省略差异按合同核对，没有官方业务写入。

正式客户端另核对关键词和订单的有限样本及受控错误；自然遇到的 `40100` 进入共享冷却。日预算返回官方 `50000`，原因未核实，只记录 `OFFICIAL_API_ERROR` 和任务失败/部分状态，不推断为权限或参数错误，也不持续重试。

D1 已完成三类真实资料读取：文档搜索、余额接口 Schema、Go 示例；资料元数据配置及系统回读成功，已绑定到用户指定的既有授权 App。Java 为隔离协议验证，未额外做真实示例读取。后续查订阅和商品 Schema 仍缺明确结束语义，未据此编造分页。

这些样本不证明 156 项全部真实可用、其他授权角色/场景或通用网络性能；不计算小样本 p50/p95。既有 SDK 预检/报表后端保持当前路线。

## 明确限制

范围决定 A_Q1 保留 156 项的安全首批读取，但不关闭原“156/156 完整分页”门禁：boost 版本列表、订阅账户列表，以及全域商品的新商品/破圈 tab 缺结束规则，三项继续 `contract_limited`。普通 tab 的分页与可投商品新商品加速场景的 `has_more` cursor 独立处理，不能相互套用。

完整 V3 Operation、可信 Broker、后台长任务、在线写入统一迁移及其余宿主验收属于原 PRD 独立目标，不由本批查询实施宣告完成。没有提交、推送、Tag、Release 或远端 Marketplace 发布。

### 2026-11-02 首次真实新聊天验收

用户授权临时启用已配置的 D1 并创建当前 Codex 验收聊天。实际宿主发现全部九个新增业务工具和三个资料工具，缺失为零。授权状态、能力目录、余额/配额健康检查，以及资料搜索、精确 Schema、Go 示例的实际 MCP 调用均在本地代理失败，返回 `no usable Ocean Watch runtime is available`；未取得官方业务或资料结果。首次验收结论为失败，不能以工具发现或安装包 stdio 通过代替调用成功。临时工具集配置已恢复并清理备份。

代码与私有 Runtime 状态核对发现：旧工具合同的首次连接失败把新版 bundle 写进全局拒绝记录，新聊天继承该拒绝后无法选用新版。修复按固定工具目录指纹隔离选择/拒绝状态，同时保持共享安装锁和活跃租约；清理保护其他合同的当前版本，并增加启用 D1 与历史拒绝状态的独立进程回归。此处仅记录根因和修复范围，复建、重装及真实重验结果仍需运行后追加。
