# AI 过程文档

本目录保存 Ocean Watch 的 AI 辅助设计、计划、调研、评审和交接材料。这些文件用于讨论与实施准备，不是当前产品行为的权威来源。

## 权威边界

- 当前运行行为以代码、配置、测试、`.codex-plugin/plugin.json`、三个 Skill 及正式文档为准；
- 过程文档中的状态、版本、行号、测试结果、环境事实和完成度在引用前必须重新核对；
- 已确认并长期有效的结论应落实到代码、测试、契约或正式文档，不能只保留在本目录；
- 未实施的设计不得写入 `README.md` 或 `docs/README.md` 作为现有能力。

## 分类

- `designs/`：目标架构、方案比较和设计决策；有实际文档后再建立稳定链接；
- [`plans/`](plans/)：分步实施与整改计划；是否进入实施以各文档状态和当前任务授权为准；
- `research/`：调研、诊断和证据记录；
- `reviews/`：评审与审计快照；
- `handoffs/`：跨会话或跨人员交接；只保留仍有独立交接价值的材料。

目录按需创建，文件命名遵循[文档中心](../README.md#存放与命名)。每份过程文档必须声明文档属性、适用范围与权威边界；完成度、环境和测试快照不能代替重新核验。
