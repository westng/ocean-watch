# 千川作品链接批量创建与追加设计

日期：2026-07-15

## 目标

`qc-plan-monitor` 接受一批抖音作品分享链接，自动识别作品、授权达人和模板商品关系。商品全域下，同一达人没有计划时按商品模板新建一条计划；已有计划（包括暂停状态）时只追加尚未存在的素材，不修改计划的预算、ROI、名称、状态或其他设置。

## 边界

- 分享短链只通过普通 HTTP 跳转解析，不操作抖音或千川网页后台。
- 跳转目标必须仍属于官方 `douyin.com` 或 `iesdouyin.com`，最终地址必须包含 `/video/{aweme_item_id}`。
- 达人授权、作品归属、商品匹配、已有计划和已有素材全部通过巨量千川官方 API 确认。
- 商品模板不保存达人、作品或素材信息。
- 默认只返回对话内结果，不生成表格文件或运行清单。

## 官方链路

1. `GET /v1.0/qianchuan/uni_aweme/authorized/get/`：一次分页同步当前广告主全部商品全域可用达人。
2. `GET /v1.0/qianchuan/file/video/aweme/get/`：先用最多 50 个 `aweme_item_ids` 批量反查作品所属授权达人，再按模板内每个 `product_id` 复查商品匹配。
3. `GET /v1.0/qianchuan/uni_promotion/list/`：获取商品全域计划，包括暂停计划，不包括已删除计划。
4. `GET /v1.0/qianchuan/uni_promotion/ad/detail/`：精确校验计划的 `aweme_id` 和商品列表。
5. `GET /v1.0/qianchuan/uni_promotion/ad/material/get/`：分页读取计划全部视频素材并按 `aweme_item_id` 去重。
6. `POST /v1.0/qianchuan/uni_aweme/ad/create/`：达人没有计划时，按模板创建计划并写入首批素材。
7. `POST /v1.0/qianchuan/uni_promotion/ad/material/add/`：已有计划或新建计划的剩余批次只追加素材。

## 数据流

1. 解析并规范化输入链接；重复作品只处理一次。
2. 同步全部授权达人，按 50 条作品一组并发查询作品归属。
3. 按模板商品逐项复查，作品不匹配任何模板商品时跳过。
4. 按数值 `aweme_id` 分组；一个达人没有合格素材时不得创建空计划。
5. 一次读取账户商品全域计划，并对候选计划调用详情接口精确确认。
6. 新达人使用模板投放参数创建计划；已有达人只计算素材差集并调用追加接口。
7. 每次写请求最多携带 100 条去重作品；新建超过 100 条时先创建，再分批追加。
8. 批次结束后统一输出新建、追加、已存在、跳过和失败结果。

## 并发与幂等

- 短链解析、达人作品查询和不同达人事务使用有上限的线程池，默认并发为 4，最大为 10。
- 同一达人在一个批次内只允许一个事务，避免重复创建。
- 真实提交时按广告主加跨进程锁；锁内重新读取官方计划和素材状态。
- 不依赖本地计划映射。创建响应丢失或追加结果不确定时，重新运行会依据官方计划和素材列表恢复幂等。

## 跳过与失败

以下情况跳过当前链接并继续处理：链接无效、跳转越界、作品不属于已授权达人、达人不可用于商品全域、商品不匹配、素材已经存在。某达人所有作品均被跳过时不创建计划。

官方查询失败、计划出现多条精确匹配、创建失败或追加失败记为失败，但不终止其他达人。输出保留非敏感官方 `request_id`、计划 ID、作品 ID 和简短原因，不输出 Token 或密钥。

## 验收

- 短链和完整链接均能稳定提取作品 ID，并拒绝非抖音跳转。
- 多链接按授权达人正确分组，商品不匹配素材被排除。
- 暂停计划只追加素材，不发起创建或修改请求。
- 已存在素材不重复追加；全部已存在时不写接口。
- 单条失败不影响其他达人，最终只输出一次批次汇总。
- 完整测试、Ruff、Skill 与 Plugin 校验通过；新增模块单独通过 Pyright。
